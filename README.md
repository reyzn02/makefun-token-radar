Token Radar: a pre-token protocol radar. It reads a sealed DefiLlama snapshot, ranks every protocol that records no token by an implied value priced off the live-token protocols in its own category, and hands in a dashboard with the board, a detail view for each protocol, filters, and a farm plan with costs and times for every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
